## 🛠️ Өөрчлөлт хийх заавар

### Өнгө солих
`css/style.css` файл дахь `:root` хэсгийг засах:

```css
:root {
    --primary-gold: #D4AF37;      /* Үндсэн өнгө */
    --primary-gold-light: #E5C878; /* Цайвар */
    --primary-gold-dark: #B8941F;  /* Хар бараан */
    --cream: #FAF8F3;              /* Дэвсгэр өнгө */
}
```

### Контент засах
`index.html` файлыг засах:
- Гарчиг, текст солих
- Зураг URL солих
- Бүтээгдэхүүний мэдээлэл шинэчлэх
